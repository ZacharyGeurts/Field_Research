Why entropy sits in the research path

We did not add thermodynamics because it sounds serious. We added it because irreversible work has a budget — Landauer’s limit shows up as operator-facing thermal guard, not as a combinatorics gate that closes a fantasy tree.

v1 coupled heat to combinatorics cycles. v2 decouples them:

  • Heat may shed capture, USB autosuspend, excess draw
  • Heat does not require walking facet trees or fusing plates
  • Cold path overhead target: 0% when idle (field-thermal-guard)

Landauer, Shannon, Maxwell — creditors

Field Primer honors them as creditors. Here they are operational:

  • Landauer: erasing information costs energy. Autosanitize and paranoia block are operator choices with receipts.
  • Shannon: surprise in packet classification — proxy entropy in panels, not calorimeter joules. Label honestly.
  • Maxwell: gatekeeper sorts good/bad flows. Heaven passes at zero nft cost when calm.

Metaphor: Maxwell’s demon as gatekeeper is teaching language. Implemented: nft / gatekeeper paths and thermal cold-path zero when idle.

Thermo slots without plate sources

Queen / engine zero-cost 4-slot already seals THERMO at compile/boot: ThermoAccountant, entropy budget, FCC scale. Tamper aborts; runtime tax 0 on the sealed compare.

v2 research conclusion: thermo is a GuardChip / HostChip slot, not a meld plate named ironclad_reality_field that must refresh with thirty peers.

Entropy oracle — receipts without pretending

Oracle writes human-readable posture. It does not replace a bench harness. Chapter 13 lists measured ops/s from Grok16 speed bench.

Rule: proxy entropy in panels; joules only when measured.

Clean voltage and diagnostic

When thermal hits crit, diagnostic collapses the capability mask (Chapter 11). No plate refresh storm. No combinatorics skip list. Generation bumps; baseline-only work remains.

Research conclusion

Entropy is the receipt that time ran forward. v2 keeps the receipt and deletes the heat-gated tree religion.
